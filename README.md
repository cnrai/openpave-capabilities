# openpave-capabilities

cnrai-curated catalog of **Capabilities** for OpenPAVE — MCP server entries
consumed by the experimental Capabilities feature ([cnrai/openpave#2638]).
Skills continue to live in [cnrai/openpave-marketplace]; this repo indexes
**MCP servers only**. The OpenPAVE server merges both catalogs at read time
and addresses entries with kind-qualified IDs (`mcp:<id>` / `skill:<name>`).

Entries are added by cnrai maintainers only (no user publish flow in v1).
See `capabilities.yaml` for the schema.
